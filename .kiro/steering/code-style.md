# Safe Line — Code Style

## Python

**Version and tooling.** Python 3.12. `ruff` for lint and format, `mypy` for types, `pytest` for
tests. All three must pass before a commit; CI blocks the merge otherwise.

**Types.**
- Every public function is fully annotated. `mypy --strict` must pass on `backend/core/`.
- `from __future__ import annotations` at the top of every module.
- Prefer `X | None` over `Optional[X]`, `list[X]` over `List[X]`.
- Ports are `typing.Protocol`, never ABCs — adapters need no inheritance and tests can pass plain
  fakes.

**Structure.**
- Pipeline stages are **pure functions**: one Pydantic model in, one out. No I/O, no globals, no
  module-level mutable state.
- Side effects live in adapters, reached through a port.
- Dependencies are injected as keyword-only arguments: `def f(x: X, *, ocr: OcrPort) -> Y`.
- `backend/core/` imports nothing external. See `project-rules.md` §8.

**Pydantic.**
- Boundary models inherit `Strict` (`extra="forbid"`, `frozen=True`).
- Validate at the boundary, then trust the model inside the core.

**Errors.**
- No bare `except:`. No `except Exception` without re-raising or a logged, named reason.
- Raise a `SafeLineError` subclass with a stable `code`. Add a new subclass rather than overloading
  an existing one.
- A single-page failure must never abort a batch.

**Logging.**
- `structlog` only; never `print`, never the stdlib `logging` directly.
- Bind context: `log.info("stage_done", job_id=..., page_id=..., stage="S4", duration_ms=...)`.
- Never log a field value, a form text, a crop or a key. The redaction processor is a safety net,
  not a licence.

**Docstrings.** One line for anything non-obvious, stating **units** and **failure mode**:
```python
def measure(page: PageRaw, *, ocr: OcrPort) -> PageMeasurement:
    """Measure orientation (degrees), skew (degrees), blur (Laplacian variance).
    Never raises; an uncomputable measurement reports its neutral value."""
```

**Thresholds.** Never a bare literal in business logic. Read from `Settings` or
`config/models.yaml`. If a constant is genuinely structural, name it in `UPPER_SNAKE` with a
comment giving its justification.

**Tests.**
- `tests/unit/test_<module>.py`, function names `test_<behaviour>_<condition>`.
- One behaviour per test. Prefer `pytest.mark.parametrize` over loops.
- Fake adapters, not mocks, for ports. Use `FixedClock` for anything time-dependent.
- Golden-case fixtures live in `backend/tests/fixtures/`; synthetic images are generated by code so
  CI works without `reference/`.

**Imports.** Standard library, third party, first party — `ruff` enforces the order. No wildcard
imports. No circular imports between pipeline stages; stages communicate through models only.

## TypeScript

**Config.** `strict: true`, `noUncheckedIndexedAccess: true`. `tsc --noEmit` must pass.

**Components.**
- Function components only. No class components.
- Props are an explicit named `interface`, never `any`.
- One component per file; the filename matches the component.
- Hooks in `src/lib/`, extracted as **pure reducers plus a thin hook** so logic is testable without
  rendering.

**State.**
- Server state through TanStack Query only. No manual `useEffect` fetch.
- SSE events update cache entries directly; never refetch the whole job on every event.
- Mutations are optimistic with rollback on failure.
- Local UI state with `useState`/`useReducer`. No global store.

**Styling.**
- Tailwind classes from the tokens in `tailwind.config.ts`.
- **No literal hex outside `tailwind.config.ts` and `src/design/tokens.ts`.** ESLint enforces this.
- Logical properties only: `ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`. Never `ml-*`/`mr-*`.
- Interactive primitives from Radix, so focus trapping and ARIA are correct by construction.

**Hebrew text.** Every string lives in `src/copy/he.ts`. No literal Hebrew in a component. See
`ui-hebrew.md`.

**Tests.** `*.test.tsx` beside the unit under test or in `tests/unit/`. Playwright specs in
`tests/e2e/`. axe assertions in `tests/a11y/`.

## Git

**Branches.** `feat/t<NN>-short-slug`, `fix/t<NN>-...`, `docs/...`, `chore/...`

**Commits.** Conventional Commits with the task number:
```
feat(engine): add barcode sweep across four orientations (T11)
fix(scoring): cap repaired values at level C (T14)
test(security): add prompt-injection fixture (T27)
docs(plan): fill ablation table with held-out numbers (T30)
```

**PRs.** Title `T<NN> — <task title>`. Description includes before/after metrics for
accuracy-affecting changes. One PR per task. No self-merge. Rebase before merge, squash so `main`
reads as one commit per task.

**Dependencies.** Pinned to a patch range in `pyproject.toml` and exact in `requirements.txt`. A new
dependency needs a one-line justification in the PR and a licence check against the table in
`docs/PLAN.md` §3.7.
